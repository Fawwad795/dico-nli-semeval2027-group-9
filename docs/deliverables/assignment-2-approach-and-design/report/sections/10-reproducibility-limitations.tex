\section{Reproducibility and limitations}
\label{sec:reproducibility}

\subsection{Reproducibility}

Training runs use seeds 13, 42 and 1234, and we report the mean and sample standard deviation over all three. For a given seed, the encoder and the decoder systems use the same grouped split of train. All systems share the development set and one fixed scorer, called through \texttt{dico\_nli.scoring.score}.

To compare two systems we use a paired bootstrap with 10,000 resamples and seed 13 \citep{berg-kirkpatrick-etal-2012-empirical}. It resamples source pairs, so both orders of a pair stay together, and reports the difference with its 95\% percentile interval. We also apply the exact two-sided McNemar test to the two systems' per-instance correctness \citep{mcnemar1947}. A difference counts as real on a metric only when its bootstrap interval excludes zero.

We ran both tests on the fixed Assignment 1 predictions. DeBERTa seed 13 is separated from the best classical system on all four metrics, with a weighted F1 difference of 0.228, interval $[0.175, 0.282]$. The same tests also separate two seeds of the same encoder on weighted F1: seed 13 exceeds seed 1234 by 0.029, interval $[0.002, 0.057]$, McNemar $p = 0.041$, while the \SoftCons{} and \HardCons{} intervals include zero. A single favourable seed can therefore pass a paired test on this development set, so claims about the proposed method rest on the mean over three seeds, with paired comparisons matched by seed.

Every run folder records its seed, the data and code commits and the exact command (\cref{app:implementation}). The Assignment 1 DeBERTa run was executed twice on T4 GPUs and produced byte-identical development predictions for all three seeds, which checks determinism for that code, seed and GPU type. A repeat of the decoder run on the GPU has not been made yet.

\subsection{Limitations}

The development set has only 277 reversible pairs, so one pair moves \SoftCons{} or \HardCons{} by 0.36 percentage points, and confidence intervals stay wide. We study English Track 1 only, and results may not carry to Spanish, Basque or the mixed-language track. Train and development share 155 of the 712 distinct development phrases (22\%), and scores are much higher when phrases recur (\cref{sec:evaluation}), which limits any claim of lexical generalisation. Finally, the public development set doubles as our test set. We never tune the method on individual development examples, but repeated inspection can still bias research choices, so final claims must be checked on the official test set once it is released.
