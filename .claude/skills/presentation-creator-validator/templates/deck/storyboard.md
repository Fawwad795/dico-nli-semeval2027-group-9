# Storyboard

One row per slide, written before any HTML. Read the titles alone, top to bottom: they should tell the whole argument.

| # | Title (the claim) | Takeaway | Support (evidence and source file) | Visual | Composition | Narrative purpose | Sources |
|---|---|---|---|---|---|---|---|
| 1 | The claim this talk makes, stated in one line | What the talk will show and why it matters. | None on the title slide. | Display title over the ruler motif. | Title: claim left, ruler above, metadata row at the foot. | Opening: state the claim. | none |
| 2 | | | | | | | |

Field guide:

- **Title**: a full sentence that states what the slide proves, not a topic label.
- **Takeaway**: the one sentence the audience should remember from the slide.
- **Support**: the evidence, with the committed file it comes from.
- **Visual**: what is drawn (bar chart of X by Y, flow of the pipeline, table of Z).
- **Composition**: the layout pattern (title and chart, split, big number, full-bleed figure).
- **Narrative purpose**: the job this slide does in the argument (context, problem, method, result, caveat, conclusion).
- **Sources**: file paths, matching `deck.json` `sources`.
