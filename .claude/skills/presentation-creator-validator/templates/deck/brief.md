# Brief

Fill this in before designing a single slide. Every later decision is checked against it.

| Field | Answer |
|---|---|
| Purpose | Why this talk exists: inform, persuade, report, defend. |
| Audience | Who is in the room, what they already know, what they care about. |
| Duration | Minutes available, including questions. Plan about one slide per minute. |
| Objective | What the audience should believe or do afterwards. One sentence. |
| Constraints | Format, template, venue, screen ratio, accessibility needs, deadlines. |
| Central message | The single claim the whole deck supports, written as a sentence. |
| Sources | Committed files every number and fact comes from. List them in `deck.json` `sources` too. |

## Central message

Write it here as one sentence. If it needs two, the talk has two messages; choose one.
