# Datasets

Metadata only. Raw data never lands in git (`.gitignore` excludes everything here except `*.md`, `*.json`, `*.yaml`, `*.yml`, `*.toml`).

For each dataset the topic uses, add a file here recording: source and version, licence, size, split definitions, the download command or script, and the checksum of the downloaded archive. Data itself goes in a subfolder that stays ignored.
